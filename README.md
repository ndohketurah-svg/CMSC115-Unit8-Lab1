
# CMSC 115 - Unit 8 Lab 1

## Project Description
This project demonstrates Java methods and JUnit testing for my CMSC 115 course at the University of Maryland Global Campus.

## Methods
- getGrade: Determines a grade based on a numerical score.
- sumEvenNumbers: Calculates the sum of even numbers.
- sumRange: Calculates the sum of integers within a range.

## Testing
The methods are tested using JUnit to verify their expected results.
## Lab Results
All three Java methods passed the zyBooks JUnit tests.
